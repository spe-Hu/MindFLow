## ⚠️ 缺失项详细分析

### 缺失 1：S1 大纲/导图双向编辑（优先级：中）

- **功能范围**：`OutlineEditor` 组件、缩进层级（2 空格=1 级）、任务语法（`[ ]`/`[x]`/`!高`/`@YYYY-MM-DD`）、双向同步、未保存警告
- **影响**：这是 PRD 定义的 3 条核心用户旅程之一（旅程 3），有明确的 AC 描述但无自动化验证
- **建议**：新建 `journey-13.ts`，覆盖大纲编辑→保存→切换导图验证同步，预计 15-20 断言

### 缺失 2：S2 导入导出（优先级：中）

- **功能范围**：
  - Settings「存储管理」JSON 导入（格式验证/版本兼容/合并覆盖）
  - Settings「导出数据」JSON 下载
  - 画布工具栏 PNG/SVG/Markdown/PDF 导出
- **影响**：数据安全相关，用户备份/恢复的核心路径无 E2E
- **建议**：新建 `journey-11.ts`，分两部分：Settings JSON 导入导出（约 10 断言）+ 画布导出（约 8 断言），预计 18 断言。
  - ⚠️ PDF 导出依赖 `simple-mind-map` 内置流程，E2E 中验证下载触发即可（无需验证 PDF 内容）
  - ⚠️ File System Access API 在 headless 中受限，建议用 `page.evaluate` 跳过文件选择对话框，直接触发 `importData()` 内部 API

### 缺失 3：S6 最近编辑列表（优先级：低）

- **功能范围**：Sidebar 展开态「最近编辑」区域、按 `last_opened_at` 倒序、最多 4 个、点击跳转
- **影响**：体验优化型功能，MVP 已可用但无自动化守护
- **建议**：合并到 `journey-12.ts`（与甘特图同 journey），约 4-6 断言

### 缺失 4：C1 甘特图（优先级：低）

- **功能范围**：`/gantt` 路由、按项目分组条形图、截止日期驱动位置、优先级默认持续时长、项目筛选 chip、折叠/展开、周导航、hover tooltip、点击跳转
- **影响**：Could Have 功能，已实现但无 E2E
- **建议**：新建 `journey-12.ts`，约 8-10 断言

### 缺失 5：PRD 旅程 3（大纲速记→转导图→批量任务化）

- **本质**：这是 S1 的「用户旅程视角」描述，与缺失 1 是同一功能的不同表述
- **建议**：同缺失 1，由 `journey-13.ts` 覆盖
