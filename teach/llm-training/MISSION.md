# Mission: 理解大模型训练全流程与底层架构

## Why

主人经常听到 "Transformer""自注意力""稀疏专家模型" 等词汇但无法形成直觉，在内容创作和技术讨论中只能停留在表层引用。掌握这些底层原理后，能自主判断技术选型、写出有深度的技术文章，并在团队交流中给出有依据的见解。

## Success looks like

- 能用一句话向他人解释清楚 Self-Attention 为什么比 RNN 好
- 能画出预训练 → SFT → RLHF 的完整流程图并解释每个阶段在解决什么问题
- 能分辨 GPT / BERT / MoE 的架构差异并说出适用场景
- 能在本地跑通一个小型 Transformer 的训练流程（至少到 SFT）

## Constraints

- 利用碎片时间学习，单次聚焦 20-30 分钟
- 优先中文 readable 的资源和解释
- 动手写代码 > 纯理论阅读
- 不追求数学严格证明，追求工程直觉

## Out of scope

- 深入 CUDA kernel 优化和分布式训练工程（这是另一个话题）
- 特定的商业产品使用（如 OpenAI API 调用技巧）
- 多模态模型（视觉-语言）的专项训练
