Self-Attention 的直觉

为什么 Transformer 能"看到"整句话，而 RNN 只能"逐字背诵"？

想象你读这句话：

"小明把书放在桌上，因为它的封面太漂亮了。"

当你读到1 这就叫长距离依赖（long-range dependency），是自然语言中最常见的现象之一。"它"的时候，你的大脑瞬间回溯到了"书"——你知道"它"指代的是书，不是桌子。这个过程只用了一眨眼的时间。

但传统神经网络做不到这一点。

1. RNN 的致命弱点：记忆力衰退

在 Transformer 出现之前，处理序列的标准方法是RNN（循环神经网络）。它的工作方式像一个2 更准确的说法是：RNN 把之前所有信息压缩成了一个固定大小的隐藏状态向量。向量维度有限，信息越多，每个词被分配到的"空间"就越小。人在逐字背诵一段长文：

  • 读第1个字时，记住它
  • 读第2个字时，把第1个字和新字"合并"成一个记忆
  • 读第3个字时，再把之前的记忆和新字合并……

问题是：每一步都在重写记忆。当句子很长时，前面的词被不断稀释，最终消失殆尽。

这被称为3 LSTM 和 GRU 通过门控机制缓解了梯度消失问题，但并未根除——它们仍然是顺序处理。梯度消失问题。LSTM（长短期记忆网络）和 GRU（门控循环单元）是两种改进版的 RNN，试图用更复杂的"门控"机制来保留重要信息，但本质仍是顺序处理。

核心洞察

RNN 的问题是结构性的：它被迫按顺序处理输入。无论多聪明的门控机制，都无法改变"每一步只能看到前面"这个事实。

2. 注意力的革命性想法：同时看所有人

2017 年，Google 团队在论文 Attention Is All You Need 中提出了一个 radical idea：

"让每个词同时看向句子中的所有其他词，
然后决定：我该关注谁？"

这就是自注意力机制（Self-Attention）的核心思想。

回到我们的例子：

"小明把书放在桌上，因为它的封面太漂亮了。"

当模型处理"它"这个词时，Self-Attention 会计算"它"与句子中每一个其他词的"关联度"。结果大概是：

词与"它"的关联度
书0.85 ← 最高
封面0.10
桌子0.03
小明0.02

然后，模型把这些关联度当作"权重"，对整句话的信息做一个加权平均——因为"书"的权重最高，所以"它"最终得到的表示中，"书"的信息占主导地位。

3. Query / Key / Value：图书馆的比喻

Self-Attention 使用三个矩阵把输入变换成三种角色。这是最常让人困惑的地方，所以用一个比喻来理解：

图书馆比喻

想象你走进一个图书馆，想找一本关于"机器学习"的书：

  • Query（查询） = 你告诉 librarian："我想找机器学习的书"
  • Key（索引） = 每本书的书名和标签（"深度学习""统计学习方法""机器学习实战"……）
  • Value（内容） = 书的实际内容

Librarian 把你的 Query 和所有书的 Key 比对，找到最匹配的几本，然后把它们的 Value（内容） 交给你。

在 Self-Attention 中，每个词同时扮演这三种角色：

  • 当它作为"当前正在处理的词"时，它是 Query
  • 当其他词被用来和它匹配时，它们是 Key
  • 匹配完成后，真正被加权合并的信息是 Value

这个过程对句子中的每一个词都执行一遍。所以"书"也会生成自己的 Query，去看看其他词中谁和它相关。

4. 数学：Scaled Dot-Product Attention

你不需要背诵这个公式，但需要理解它在做什么。Attention 函数的核心只有三步：

Step 1：算 Query 和 Key 的相似度

我们把所有词的 Query 向量拼成矩阵 Q，所有词的 Key 向量拼成矩阵 K。然后做一次矩阵乘法：

scores = Q @ K.T

结果的形状是 [句子长度, 句子长度]。第 i 行第 j 列的数字，表示第 i 个词认为第 j 个词有多重要。

Step 2：Softmax 归一化

原始分数可能很大或很小，需要用 softmax 把它们变成概率分布（每行之和为 1）：

weights = softmax(scores / sqrt(d_k))

这里的 sqrt(d_k) 是4 当向量维度很大时，点积的数值也会很大，导致 softmax 的输出两极分化（接近 0 或 1）。除以 √d_k 可以防止这个问题，称为 scaling。缩放的技巧（scaling）。不除以 √d_k，梯度反而会变得不稳定。

Step 3：用权重对 Value 加权求和

output = weights @ V

这就是 Self-Attention 层的最终输出——每个词都得到了一个"看了整句话之后"的新表示。

5. 十行 PyTorch 看懂 Attention

import torch
import torch.nn.functional as F
import math

def self_attention(Q, K, V, mask=None):
    """
    Q, K, V: [batch_size, num_heads, seq_len, dim]
    """
    d_k = Q.size(-1)
    
    # Step 1: 计算相似度分数
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
    
    # (可选) 屏蔽未来信息，用于解码器
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    
    # Step 2: softmax 得到注意力权重
    weights = F.softmax(scores, dim=-1)
    
    # Step 3: 加权求和 Value
    output = torch.matmul(weights, V)
    return output, weights

# 用随机数据试一把
batch, heads, seq, dim = 2, 8, 10, 64
Q = torch.randn(batch, heads, seq, dim)
K = torch.randn(batch, heads, seq, dim)
V = torch.randn(batch, heads, seq, dim)

out, attn_weights = self_attention(Q, K, V)
print(out.shape)        # [2, 8, 10, 64] —— 每个词的新表示
print(attn_weights.shape)  # [2, 8, 10, 10] —— 注意力矩阵

虽然实际代码需要考虑多头（Multi-Head Attention）、mask、dropout 等细节，但核心逻辑就是这5 如果去掉 mask、dropout 和多头拆分的包装，核心 attention 计算确实只有 5-7 行。这也是 Transformer 的美妙之处：惊人的效果来自惊人的简单。三步——而这三步，彻底改变了 NLP。

6. 为什么叫"Self" Attention？

因为 Query、Key、Value 都来自同一个输入序列。

在早期的注意力机制（如机器翻译中的 encoder-decoder attention）中，Query 来自解码器（目标语言），而 Key/Value 来自编码器（源语言）。这种 attention 是跨序列的。

Self-Attention 的特殊之处在于：Q、K、V 都是从同一句子产生的。句子自己和自己打交道，所以叫"Self"。
