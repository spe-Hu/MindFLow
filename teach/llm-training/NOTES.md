# Teaching Notes

## User Preferences

- 已有神经网络基础（理解 BP、激活函数、前馈网络），但不了解 Transformer
- 喜欢"从底层理解"，不满足于"黑盒调用"
- 对架构演进（GPT→BERT→MoE 等）有强烈兴趣
- 中文沟通，但技术术语接受英文原文
- 偏好结构化内容（表格、图示、代码示例）
- 不喜欢长篇大论，喜欢"一次搞懂一个点"

## Session Strategy

- 每节课聚焦一个"可以被问住"的问题（如：Self-Attention 为什么需要 Q/K/V 三个矩阵？）
- 每节课末尾给出一个小练习，要求用户用
自己的话回答
- 推荐视频优先（Karpathy、3Blue1Brown），其次文章，最后论文
